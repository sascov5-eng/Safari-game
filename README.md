# Платформер — 2D игра для Safari

Простая 2D-игра на HTML5 Canvas: персонаж прыгает по платформам, собирает монеты и избегает врагов.

## Возможности

- Управление клавишами (стрелки, A/D, пробел) и сенсорными кнопками на телефоне
- Сбор монет и счёт очков
- Враги, патрулирующие платформы
- 3 жизни
- Экран окончания игры и перезапуск
- Адаптивный дизайн под iPhone и десктоп

## Запуск локально

1. Открой `index.html` в браузере.
2. Играй через клавиатуру на компьютере или через сенсорные кнопки на телефоне.

## Запуск через GitHub Pages

1. Загрузи файлы `index.html`, `style.css`, `game.js`, `README.md` в корень репозитория.
2. Открой **Settings → Pages**.
3. Выбери **Source: Deploy from a branch → main → root**.
4. Сохрани.
5. Игра будет доступна по адресу:  
   `https://sascov5-eng.github.io/Safari-game/`

## Добавление на экран "Домой" (iPhone)

1. Открой игру в Safari.
2. Нажми кнопку **Поделиться** (квадрат со стрелкой вверх).
3. Выбери **На экран "Домой"**.
4. Готово — игра запускается как приложение.

## Управление

**Компьютер:**  
- Стрелки влево/вправо или A/D — движение  
- Стрелка вверх или пробел — прыжок

**Телефон:**  
- Сенсорные кнопки внизу экрана
